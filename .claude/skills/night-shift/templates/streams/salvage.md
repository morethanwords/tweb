# Спасение незакоммиченной работы из ворктри (id: salvage-a / salvage-b)

В ворктри лежит незакоммиченная работа, многие отстали от master. Цель — для каждого понять, что там, и подготовить
версию поверх свежего master, чтобы пользователю осталось только решить.

ОРИГИНАЛЫ НЕ МЕНЯТЬ (ни файлы, ни git-состояние: никаких checkout, rebase, stash, reset в них). Если ворктри
занят живой сессией (cwd процесса claude/codex внутри: `/proc/<pid>/cwd`) или правился в последние сутки —
только отчёт, без копии. Ворктри с коммитами — сначала проверь по patch-id / содержимому, не влито ли уже.

Для каждого:
1. Что это: прочитай diff, память (MEMORY.md и связанные заметки), отчёты в его `tmp/`.
2. Копия: ворктри `{{RUN}}-salvage-<имя>` от master; перенеси diff оригинала (включая неотслеживаемые файлы,
   кроме мусора и `tmp/`) трёхсторонним слиянием; разреши конфликты по смыслу обеих сторон.
3. tsc, oxlint, тесты, которые задевает изменение; одна полная волна Codex-ревью (без бесконечных раундов) —
   находки в отчёт, очевидное поправь.
4. Вердикт: «готово к влитию» / «нужно решение пользователя (какое)» / «устарело — выкинуть (почему)» /
   «уже в master». Отчёт `N/reports/<id>.md` — таблица по всем ворктри списка, затем подробности.
