# Аудит кода чтением (id: au<N>)

Этот поток почти не трогает процессор: никаких превью и Playwright, только чтение кода, tsc и отдельные файлы vitest.
Цель — настоящие дефекты (гонки, утечки, неверные условия, потерянные ошибки, отказ, запомненный навсегда,
рассинхрон кэша и сервера), а не стиль. В первую ночь такие сессии нашли больше всего самых ценных багов.

1. Возьми область: `mkdir N/claims/audit-<область>` (не вышло — следующая). Области:
   - `messages` — appMessagesManager: отправка, правка, удаление, хранилища истории, mid, альбомы; dialogsStorage.
   - `updates` — apiUpdatesManager: pts/qts/seq, дыры и getDifference, channel difference, порядок применения.
   - `networker` — mtproto: networker, transport, authorizer, tempAuthKeys, переподключения, ack, повторы, соли.
   - `workers` — superMessagePort, SharedWorker / ServiceWorker, несколько вкладок, PiP, смена аккаунта.
   - `chat-render` — путь отрисовки чата (bubbles, слайсы загрузки, прокрутка, гонки рендера; память: chat-render-races).
   - `media` — загрузка и выгрузка файлов, кэши, object URL и пины, стриминг через SW.
   - `stories`, `calls`, `payments` (звёзды, подарки, платный контент), `editor` (rich-text поле ввода),
     `folders` (папки, фильтры, архив), `settings-privacy` (приватность, сессии, 2FA, пасскод), `peers` (пользователи,
     чаты, права, статусы), `stickers`, `bots` (инлайн, клавиатуры, веб-приложения).
   Прошлые ночи уже прошли эти области — читай их отчёты (`tmp/night-*/reports/au*.md`) и ищи дальше, а не заново.
2. Читай глубоко; для широкого чтения можно субагентов. По каждому кандидату — сценарий (входные данные / состояние →
   неверный результат) и файл:строка. Проверь: трассировкой кода и, где можно, unit-тестом, который падает до
   исправления. Неподтверждённое не чини — запиши как «подозрение».
3. Подтверждённое — исправь в ворктри `{{RUN}}-au-<область>-<slug>` (одно изменение — один ворктри) с регрессионным
   vitest, tsc, oxlint, ревью Codex (до 3 раундов).
4. Отчёт `N/reports/<твой id>.md`: область, что прочитано, находки (подтверждено / подозрение / ложная тревога и
   почему), исправления с путями.
5. Закончил область — следующая. Области кончились — `N/BACKLOG.md`.
