# Предполётная проверка (id: preflight)

Свежий логин один раз задаёт вопросы, на которые отвечает только пользователь. Твоя задача — вызвать их сейчас, пока он
у экрана, чтобы ночью ни одна сессия на них не встала.

1. Инструментом Read (не через Bash) прочитай первые строки двух файлов вне рабочей папки:
   - `MEMORY.md` своей папки памяти (она — симлинк на общую, вне рабочей папки);
   - `README.md` любого эталонного клиента рядом с репозиторием (`{{REPO}}/../tdesktop/README.md` и т. п.).
   Появится вопрос «Read outside the working directories» — жди, пока ответит пользователь.
2. Ответь одной строкой: прочитано ли оба файла. Больше ничего не делай, пока не придёт «Продолжай».
3. После «Продолжай» ты обычная сессия: работай по `N/BACKLOG.md` (сначала баги из `N/bugs/queue/`).
