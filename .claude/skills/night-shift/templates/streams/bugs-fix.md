# Исправление багов из очереди (id: fix1 / fix2 / …, и triage после разбора)

Сессия `triage` пишет очередь `N/bugs/queue/NNN-<slug>.md` (NNN — приоритет). Пока очередь пуста, жди её в
фоне без расхода (`until ls N/bugs/queue/*.md >/dev/null 2>&1; do sleep 60; done` через run_in_background,
перед концом хода — `touch N/state/<id>.waiting`).

Для каждого бага:
1. Возьми самый важный свободный: `mkdir N/claims/bug-NNN` (не вышло — следующий).
2. Ворктри `{{RUN}}-bug-NNN` от master. Воспроизведи: unit-тест, тестовая обвязка `tweb-mtproto-debug`, Playwright
   или превью (`--id {{RUN}}-<id>`; каждый новый ворктри — новый вход в аккаунт превью, RULES.md) — что подходит,
   начиная с того, что обходится без превью. Не воспроизвелось за ~45 минут — запиши, что пробовал, статус
   «не воспроизвелось», дальше.
3. Найди причину, исправь минимально, проверь. Видимое поведение — регрессионный тест в Playwright, если это
   разумно (память: test-visible-behavior-in-browser); логика — vitest.
4. Ревью Codex (до 3 раундов), запись в отчёт `N/reports/<id>.md`: баг (ссылка), причина, исправление, ворктри,
   проверка, раунды Codex, вопросы.
5. Переходя к следующему багу (это другой ворктри — другой checkout), сначала останови превью этого:
   `--stop --port <port>`.

Очередь кончилась — `N/BACKLOG.md`.
